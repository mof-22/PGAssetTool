# PGAssetTool

English version: [README.md](README.md)

Unity 2021.3（IL2CPP）で作られたピクセル調シューターの、アイテムを改造するための Windows ツールです。
アイテムとそれが使っているものを丸ごと見つけ出し、普通のソフトで編集できるファイルとして書き出し、
編集した結果を `.pgmod` にまとめてゲームに導入します。書き換えるバンドルは必ず先にバックアップを取るので、
やったことは全部元に戻せます。

対象は武器とそのスキンです。ゲームの他の見た目アイテム — 帽子・ケープ・マスク・ブーツ・ペット・
グライダー・乗り物・アバター — も中身は同じ構造でコマンドラインからは一覧できますが、**ウィンドウでは武器が
仕上がるまで武器だけを表示**しています。

ゲームのデータそのものは一切同梱していません。パックは「何をどう変えるか」を書いたもので、指しているのは
プレイヤー自身のインストールにあるアセットです。

---

## 入手する

Windows x64 が要ります。ビルド済みのものを動かすだけなら他には何も要りません。

自分でビルドするなら .NET 10 SDK が要ります。

```
dotnet publish src/PGAssetTool.Gui -c Release -o dist
```

`dist/PGAssetTool.exe` はこれ一つで動く実行ファイルで、**書き出すものは全部その隣に置きます**。
レジストリも `%APPDATA%` も使いません。

起動すると Steam 経由でゲームを自分で探します。別の store 版を使っている場合や、コピーに対して作業
したい場合は **File → Options** でフォルダを指定してください。

## 最初の1つを作る

武器を塗り替える、最初から最後まで。10分ほどで、途中で嫌になっても全部元に戻せます。

**1. 武器を探す。** **Browse** タブにゲーム内の名前で武器が並びます。検索欄には番号でも、ゲームが持っている
どの言語の名前でも、その一部でも通ります。

**2. 眺める。** 武器を選ぶと、それが使っているものが全部出ます — モデル、テクスチャ、音、スキン。
テクスチャをクリックすれば表示され、音はスペースキーで再生・停止、モデルはマウスで回せます。
**何を変えるか決める前にこれをやる価値があります。**

**3. 書き出す。** `Ctrl+E`、または **File → Extract weapon**。**ワークスペース**ができます — PNG や WAV や
glTF といった普通のファイルが入ったフォルダと、それぞれが何から来たかを記録した小さな `pgmod.json` です。
武器全体ではなく特定のスキンだけを触りたいときは、ツリーの上のドロップダウンで先に選んでください。

スキンのある武器には、プレイヤーが一度でもスキンを変えたかどうかで**2通りの既定の見た目**があります。
もう一方が武器本体のテクスチャの複製で塗られている場合、**編集は両方に書き込まれます**。
別の絵で塗られている場合は両方を書き出し、Editor にそう表示されます。

**4. ファイルを編集する。** PNG のどれかを好きなお絵かきソフトで開いて、変えて、保存します。
**Editor** タブはフォルダを見張っているので、保存した瞬間に「編集済み」の印が付きます。

フォルダを探しに行く代わりに、**ファイルをウィンドウにドラッグしても入ります** —
`ultimatum.png` を落とせば `ultimatum.png` のところに入ります。

**5. 何をしたか確かめる。** Editor はゲームのものとあなたのものを見せます — **Side by side** で並べるか、
その場で切り替えるか（小さな違いはこちらのほうが見つかります）。どちらでも**2つは連動します** —
モデルは一緒に回り、同じテクスチャを着るので、**残る違いはあなたが加えた変更だけ**になります。

**6. ゲームに入れる。** **Build and apply**。先にゲームを閉じてください — 起動中は書き込みを拒否します。
ゲームを起動して、自分の武器を見てください。

**7. 気が変わったら。** **Manager** タブに導入済みのものが並びます。**Turn off** はアンインストールせずに
ゲームだけ元に戻し、**Remove** は完全に取り除きます。どちらでも、各バンドルは最初の書き込み前に取った
コピーに戻ります。

---

## 3つのタブ

**Browse** — 武器の一覧と、選んだものが参照しているもの全部のツリー。
プレビューはここです。テクスチャ、音、そしてモデル — 回して、そのアイテム自身のスキンを着せて、
ボーンに乗っているモデルなら**自前のアニメーションを再生**できます。
`Ctrl+Shift+R` で**実際に差し替えられるものだけ**に絞れます。普段はこちらのほうが見やすいはずです。
ここに出るのは**導入済みのMODに関係なく、ゲーム本来の状態**です。抽出されるのもゲーム本来のものなので、
MODの見た目はゲーム内で確かめてください。

**Editor** — 抽出済みのワークスペース、どのファイルを編集したか、そしてあなたのものとゲームのものの比較。
パックの名前・作者・バージョン・説明・絵はここで設定します。複数のワークスペースをまとめて選んで、
まとめてビルド・導入できます。

**Manager** — 導入済みのもの。パックは**どのアイテムの、どの見た目を変えるものか**で仕分けられ、
左の棚から辿れます（検索もできます）。タイルにはパック自身の絵が出ます。
自分の記録だけでなく**ゲーム本体も読む**ので、他のものに書き換えられたバンドルは、誰かがその上に
インストールする前に見えます。

## 人のパックを入れる

`.pgmod` をウィンドウにドラッグしてください。それだけです。導入されて Manager に出ます。

**複数まとめて落とせます。**インストールはゲーム全体の組み直しなので、まとめたほうが速く、安全です。

## ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+1` `Ctrl+2` `Ctrl+3` | Browse / Editor / Manager |
| `Ctrl+F` | そのタブの検索欄へ |
| `Ctrl+E` | 選択中の武器を抽出 |
| `Ctrl+Shift+E` | 選択中のアセットだけを抽出 |
| `Shift+A` | 今見えている画像のアルファを表示 |
| `Ctrl+Shift+R` | 差し替えられるものだけ表示 |
| `Ctrl+R` | ゲームをディスクから読み直す |
| `F5` | ワークスペースを読み直す |
| `Delete` | 選択中のワークスペースを削除／選択中のMODを取り除く |
| `Ctrl+,` | オプション |

モデルが表示されているとき：

| | |
| --- | --- |
| ドラッグ | 回す |
| `Shift` + ドラッグ | 傾ける |
| 中ボタン + ドラッグ | 枠の中で動かす |
| ホイール | 近づく・離れる |
| `R` | まっすぐに戻す |

Manager では `Ctrl` + ホイールでタイルの大きさが変わり、**`Shift` を押している間 Remove が
「Remove and delete」に変わって**、控えのパックファイルごと消します。

## パックを配る

**Build pack** でワークスペースに `.pgmod` ができます。誰にでも渡せます — ゲームのデータを含まず、
相手のインストールにあるアセットを指しているだけだからです。

パック詳細の *Protection* で **Protect this pack** を選ぶと（または保護が有効な Options に従わせると）署名も付きます。署名は「中身がその鍵の持ち主が入れたものである」ことを
示すので、**後から書き換えられたパックは書き換えられたものとして表示されます**。作者名も一緒に署名されるので、
他人の作品にあなたの名前を移したり、あなたの作品から名前を外したりはできません。

防げないのは、**別の鍵で署名し直すこと**です。原理的に防げません。その代償は fingerprint で、確認する
価値があるのはそちらです — 名前は誰かが打ち込んだもの、fingerprint は持っているものです。
自分のものを公開しておけば、署名し直されたパックと本物を見分けてもらえます。
自分の fingerprint は **File → Options** にあります。

## うまくいかないとき

**ゲームが見つからない** — 自動検出は Steam 経由で、このゲームはそこだけで売られているわけではありません。
**File → Options** で自分で指定してください — ゲームの `*_Data` フォルダを含んでいるフォルダです。
**ゲームデータのコピーを指しても動きます。**普段遊んでいるインストールに触らずに試すには、それが一番安全です。

**「ゲームが起動しています」** — 閉じてください。起動中はゲームのファイルに一切書き込みません。
バンドルをゲームの足元で書き換えると、中途半端に壊れたファイルが残るからです。

**バンドルが他のものに書き換えられている** — Manager がそう言います。コマンドラインの `verify` は、
ゲームが記録したハッシュと違う全バンドルを挙げ、**そのうちどれが導入済みMODで説明が付くか**を示します。
他のツールが書いたものは、こちらに元のコピーがないので戻せません。

**パックが適用できない** — 理由が出ます。たいていはゲームの更新でアセットが移動した場合です。
パックは id だけでなく**アイテムの名前とクラスも記録している**ので、id で見つからなくなったときは
そちらで探し直します。ゲームがアセットを**別のバンドルに移した**場合も、パックの対象アイテムの
バンドルから探し、見つかった先を Manager が表示します。見つけられないのは、そのバージョンの
ゲームに存在しないアセット（後から追加されたスキンなど）だけです。

**ゲームが更新された** — 更新はMODを書き込んだバンドルを置き換えるので、Manager ではオンのままでも
**MODはゲームから消えています**。ツールは起動時にそれに気づいて上部に表示し、**Reapply everything** で
新しいバンドルに書き直せます。

**全部なかったことにする** — Manager で全MODを Remove してください。各バンドルは最初の書き込み前の
コピーに戻ります。

## コマンドライン

GUI でできることは全部あります。実行ファイルは
`src/PGAssetTool.Cli/bin/Release/net10.0-windows/win-x64/pgassettool.exe`、または：

```
dotnet run --project src/PGAssetTool.Cli -c Release -- <コマンド>
```

| コマンド | 動作 |
| --- | --- |
| `info` | 検出したインストールとバージョンを表示。 |
| `weapons [<絞り込み>]` | 武器一覧。名前・スラッグ・タグ・プレハブ名で絞れます。 |
| `items [<種別>]` | 武器以外の種別 — 帽子・ケープ・マスク・ブーツ・ペット・グライダー・乗り物・アバター — の一覧、または指定した1種別の全件。 |
| `show <アイテム>` | 1つのアイテムと、それが参照しているものすべて。武器はゲーム内番号（`819`）、プレハブ名（`Weapon1257`）、スラッグのどれでも。それ以外は `items` が出す id です。**ゲーム内番号とプレハブ番号は別の連番です。** |
| `extract <アイテム>` | アイテムに属するものを全部書き出し。`--workspace` を付けるとパック化できる `pgmod.json` も書きます。 |
| `pack [<ディレクトリ>]` | ワークスペースから `.pgmod` をビルド。抽出以降に編集されたファイルだけが入ります。 |
| `apply <パック>` | `.pgmod` をゲームに導入。 |
| `mods` | 導入済み一覧。 |
| `enable <id>` / `disable <id>` | MODを有効化／アンインストールせずに無効化。 |
| `remove <id>` | MODをアンインストール。 |
| `verify` | 全バンドルを、ゲームが記録したハッシュと照合。 |
| `consolidate` | ダウンロード済みキャッシュを空にすると何が変わるかを報告。`--apply` は何も変わらないコピーだけを削除。 |

| オプション | 動作 |
| --- | --- |
| `--game <ディレクトリ>` | 検出したものではなくこのインストールを使う。想定どおりの構成なら何でもよいので、ライブのゲームではなくコピーに対して作業できます。 |
| `--language <バンドル>` | 名前を読む翻訳バンドル（既定 `l_en-gb`）。 |
| `--out <ディレクトリ>` | 出力先。`extract` の既定は `./workspace`。 |
| `--author <名前>` | マニフェストに記録されます。 |
| `--skin <id か 名前>` | 素の武器ではなく、指定したスキンを書き出す。何があるかは `show` が出します。 |
| `--opaque` | アルファチャンネル無しでテクスチャを書き出す。多くのテクスチャはそこに透明度ではなく発光を持っていて、そのまま開くとほぼ見えないからです。アルファ無しで戻したものには元のアルファが付け直されます。 |
| `--whole` | テクスチャを丸ごと書き出す。既定では**どのモデルも使わない部分を透明**にして、実際に見える範囲だけを残します。 |
| `--protect` | ビルドしたパックに署名し、zip として開けないようにする。 |
| `--force` | `apply` をそのまま進める。既に改変済みのバンドルでもバックアップを取り、署名済みパックがビルド後に改変されていても導入します。 |
| `--fast` | 書き戻すバンドルの圧縮を軽くする。その工程が約4倍速くなり、バンドルは約1.2倍になります。ゲーム側の読み込み速度は変わりません。 |
| `--rebuild` | 既に正しい内容が入っているバンドルも含めて全部作り直す。通常はそのまま残します。 |

```
pgassettool weapons crystal
pgassettool extract 819 --workspace --out workspace
pgassettool pack workspace/0819_something
pgassettool apply workspace/0819_something/something.pgmod
```

## 何を変えられるか

| 対象 | 元にするファイル | |
| --- | --- | --- |
| テクスチャ | `.png` | 好きなソフトで編集 |
| モデル | `.glb` | 好きなソフトで編集 |
| 音 | `.wav` `.mp3` `.ogg` | 好きなソフトで編集 |

どれも**普通のソフトで開けるファイル**で、このツールが「差し替え可能」と呼ぶのはそこまで揃ったものだけです。
抽出で書き出されるのもこの3種類だけです。マテリアルやアニメーションなど、編集して戻せる形式が無いものは
**書き出さずにゲームの中に残します**。

**コンポーネントだけは例外**です。このツールは表示もしませんし書き戻しもしません。コンポーネントは
ゲームが「そのものが何をするか」を決めている場所で、ここは**見た目と音のためのツール**だからです。

## まだできないこと

- **落書き・ガジェット・装甲。** ツールではなくゲーム側にありません。落書きはルックアップテーブルに
  1件も存在せず、ガジェットはレジストリの無いプレハブ2個、装甲はレジストリに32件あってプレハブが
  0件です（装甲は数値とショップアイコンだけで、そのアイコンもバンドルの外にあります）。
- **`.assets` への書き込み**（`*_Data` 以下のファイル）とスプライトアトラス。ここで扱っているのは
  すべて AssetBundle です。
- **フォント・シェーダー・マテリアル。** 編集するための形式が無いので、書き戻しもしません。

## ツールを改造する人へ

[DESIGN.md](DESIGN.md)（英語）に、なぜこの作りなのかが書いてあります — アイテムの部品をどうやって
見つけているか、パックとは何か、ゲームの更新にどう追従するか、そして**一見おかしいが理由があって
そうなっている箇所**。

```
dotnet test -c Release
dotnet run --project src/PGAssetTool.Gui -c Release -- --self-test
```

`dotnet test` はゲーム不要で、CI が回すものです。`--self-test` が本当の検査で、
実際のインストールに対してツール全体を動かし、終わったら元に戻します。

`classdata.tpk`（Unity のエンジンクラスデータベース）はコアアセンブリに埋め込まれています。
`*_Data` 以下のファイルは TypeTree 無しでビルドされているため必要です（AssetBundle は自前で持っています）。
**Unity 標準のクラスを記述したものだけで、ゲーム独自のコードとは無関係です。**
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) を参照してください。
